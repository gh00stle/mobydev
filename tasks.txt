

Task 3: Applying pseudo-classes to different elements
1. Create several blocks (`div`) containing text elements and links.
2. Apply the pseudo-classes `hover`, `focus`, `first-child` and `last-child`:
  - Change the color of the link when you hover the cursor over it.
  - Apply styles to change the appearance of odd text elements inside the block.

Task 4: A combination of pseudo-classes
1. Create an HTML page with several blocks of content.
2. Combine different pseudo-classes:
  - Apply styles to the elements that are the first child elements and change when the cursor is hovered over.
  - Add styles for the elements that are in focus and are the last child elements.

The final page
1. Collect all the examples in one HTML document.
2. Create a page with comments explaining how pseudo-classes work and in what cases they can be used.
3. Make sure that all styles are applied correctly.
